## MCP 기능

- `search_docs`: 제목·본문 통합 검색
- `search_sections`: 섹션 검색
- `get_document`: 문서 조회
- `list_datasets`: 코퍼스 데이터셋 목록
- `get_stats`: 현재 프로세스의 인덱스 통계
- `recommend_datasets`: 키워드·동의어 매칭 후보 추천
- `compare_datasets`: 설명서·가이드 수, 섹션 수, 문서 크기, 주요 섹션 라벨 비교
- `semantic_search`: 벡터(의미) 검색 — 어휘가 달라도 의미가 같은 섹션 검색 (실험적)
- `hybrid_search`: 어휘(FTS+동의어) 우선 + 의미(벡터) 보조 RRF 결합 — **기본 권장 검색**

### 벡터 검색 품질 평가 (2026-10-28, 개정)

- 초기 3종 모델(MiniLM·E5-base·bge-m3) 실패의 주원인은 모델이 아니라 **구현 문제**였습니다: ① 섹션당 앞 1,600자만 임베딩해 5만 자 가이드의 대부분이 검색 대상에서 누락 ② 빈 섹션·제목만 있는 섹션도 벡터에 포함 ③ 질의·문서 전처리 불일치.
- 이를 해결한 **청크 인덱스**(`build_chunk_index.py` → `mfg_chunks_20261028_v2.db`)로 교체: 원문 전체를 512토큰 겹침 청크로 분할(6,542청크), 빈 섹션 제외, 빌더·런타임 동일 전처리·모델 revision 검증, 배치 체크포인트로 재개 가능.
- `semantic_search`는 청크 벡터 검색으로 동작하며, `hybrid_search`는 자연어 질의 정규화 + 어휘(FTS+동의어) 우선 + 벡터 보조(0.4) RRF 결합. 벡터 오류 시 어휘 결과로 폴백하며 상태·경고를 응답에 명시.
- 검색 결과는 원문 스니펫과 출처를 제공하며, 근거 부족 질문에는 "후보일 뿐 확정 근거 아님" 안내를 포함합니다.
- 재빌드: `uv run --with sentence-transformers python rag/build_chunk_index.py` (체크포인트 재개 지원).

### 최종 검증 (2026-10-28, 56건 전부 통과)

- 인덱스: 6,542청크(빈 섹션 1,312개 제외, 원문 3,429,383자 커버 — 갭 없음, 임베딩 노름 1.0±1e-6, 원문 슬라이스 정확)

추천은 임베딩 기반 의미 검색이 아닙니다. 추천 점수는 적합성 확률이 아니며 낮은 관련도 후보가 섞일 수 있습니다. 비교 도구는 기술 사양·라벨·성능 전체를 자동 검증하는 도구가 아닙니다. 기술 비교와 제안서 근거 인용은 해당 문서 원문을 조회하여 확인하세요.
